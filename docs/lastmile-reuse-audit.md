## Security, licensing and configuration

`providers/integration-environment.ts` reads only an explicitly configured absolute authorized integration file. It allowlists provider settings, never imports another application's database/browser configuration, and leaves secret values server-side. The LastMile credential path is explicitly selected in private local configuration; no unrelated credentials were searched or copied. Reports contain presence/status only. Source operations remain role-, building- and workspace-scoped. Explicit inference consent is required; explanation jobs make one attempt to avoid automatic ambiguous/billable replay.

No root redistribution license was identified for either project's application code. Adapted behaviors are reimplemented around documented provider contracts, rather than blindly copying LastMile application modules. The unmodified Engine snapshot is separately Apache-2.0 licensed. Geist's shipped license is retained. FontAwesome and font CDN/video usage rights must be confirmed for public distribution; remote availability does not grant rights. OSM-derived data retains ODbL attribution; taxi-source usage/freshness must be established before redistribution. Private raw evidence is not public fixture data.

See [live verification](live-integration-verification.md) for current external results and [design system](ui-design-system.md) for the exact UI contract. Event qualification is an organizer decision, not inferred from names or conformance alone.
